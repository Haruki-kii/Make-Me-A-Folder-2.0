Make Me A Folder

A simple desktop application that creates a ready-to-use project folder.

Features
    1.Creates a project folder with automatic numbering.
    2.Generates:
        README.md
        main file
        test file
    3.Supports Python or custom file extensions.
    4.Saves the last-used project location.
    5.Optionally opens the project in Visual Studio Code.

Usage
    1.Enter a project name.
    2.Choose a project location.
    3.Select a file extension.
    4.(Optional) Add project notes.
    5.Click Create Project.
